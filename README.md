# SpendWise (practice build)

A personal expense tracker: React frontend, Flask API, Postgres database,
Docker, Nginx, CI/CD and Azure deployment.

Built as a learning exercise by the DevOps lead.

## Structure
- backend/    Flask REST API
- frontend/   React app
- database/   SQL schema
- nginx/      Reverse proxy config
- monitoring/ Health checks and monitoring
- docs/       Documentation
